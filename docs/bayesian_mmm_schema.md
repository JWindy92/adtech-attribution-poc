# Bayesian MMM Schema Transformation

This document traces how data schema changes throughout the Bayesian MMM pipeline, from raw input to final attribution output.

## 1. Raw Input Data

**Source**: DataFrame passed to `BayesianMMMModel.fit()`

```
Shape: (n_weeks, n_channels + 1)

     channel_0  channel_1  channel_2  channel_3  conversions
  0       ...        ...        ...        ...          ...
  1       ...        ...        ...        ...          ...
 ...      ...        ...        ...        ...          ...
 51       ...        ...        ...        ...          ...

Total: 52 rows (weeks), 5 columns (4 media + 1 target)
```

**Column Types**:
- `channel_0` through `channel_N`: float64 (media spend in dollars/units)
- `conversions`: float64 (total weekly conversions)

---

## 2. Inside PyMC Model

When `fit()` builds the PyMC model, data is converted to numpy arrays and PyMC variables are created:

```
spend_data:    shape (52, 4)  - numpy array of media spend
conversions:   shape (52,)    - numpy array of conversions

PyMC Variables Created:
  alpha[0..3]:           shape (4,)  - Per-channel saturation curve steepness
  gamma[0..3]:           shape (4,)  - Per-channel half-saturation point
  beta[0..3]:            shape (4,)  - Per-channel effectiveness coefficient
  intercept:             shape ()    - Baseline conversion level
  sigma:                 shape ()    - Observation noise
  observed:              shape (52,) - Likelihood (linked to conversions)
```

**Internal Computation**:
```
After Hill saturation transformation:
  saturated:  shape (52, 4)  = spend_data^alpha / (gamma^alpha + spend_data^alpha)
  
  mu (expected conversions):  shape (52,)
    = intercept + dot(saturated, beta)
    = intercept + (saturated @ beta)
```

---

## 3. MCMC Sampling Output (InferenceData/Trace)

After sampling with PyMC, `self.trace` contains posterior samples:

```
Posterior Samples Structure:
  
  posterior group:
    alpha[0..3]:           shape (chains=2, draws=500, dims=4)
    gamma[0..3]:           shape (chains=2, draws=500, dims=4)
    beta[0..3]:            shape (chains=2, draws=500, dims=4)
    intercept:             shape (chains=2, draws=500)
    sigma:                 shape (chains=2, draws=500)

Total: 1000 posterior samples across 5 variable groups
```

Each parameter has uncertainty quantified across MCMC chains.

## 5. Channel Contributions (Attribution)

**Generated by**: `fit()` method, posterior mean calculations

```
Shape: (n_weeks, n_channels)

     channel_0  channel_1  channel_2  channel_3
  0       ...        ...        ...        ...
  1       ...        ...        ...        ...
 ...      ...        ...        ...        ...
 51       ...        ...        ...        ...

Total: 52 rows (weeks), 4 columns (channels)
```

**Calculation**:
```
For each week w and channel c:

  contribution[w, c] = saturated[w, c] * posterior_mean_beta[c] 
                     + (posterior_mean_intercept / n_channels)

Where:
  saturated[w, c] = spend[w, c]^α[c] / (γ[c]^α[c] + spend[w, c]^α[c])
  
  α[c], γ[c], β[c] = posterior means from trace
```

**Returned by**: `model.get_contributions()`

## 6. Full Pipeline Data Flow

```
INPUT (fit)
    ↓
    [Raw Data]
    ├─ shape: (52, 4) spend
    └─ shape: (52,)   conversions
    ↓
[PyMC Model Building]
    ├─ PyMC Variables created (alpha, gamma, beta, intercept, sigma)
    └─ computed: saturated spend, mu (expected conversions)
    ↓
[MCMC Sampling]
    ├─ 2 chains × 500 draws = 1000 samples
    └─ posterior samples for all 5 variable groups
    ↓
[Posterior Analysis]
    ├─ get_posterior_summary() → (14, 9) summary DataFrame
    └─ calculate contributions → (52, 4) contributions DataFrame
    ↓
OUTPUTS
    ├─ contributions:        (52, 4)  - weekly channel attributions
    └─ posterior_summary:    (14, 9)  - parameter inference results
```

---

## 7. Dimension Reference

```
Notation:
  n_weeks    = 52 (temporal dimension)
  n_channels = 4  (media channels)
  n_params   = n_channels * 3 + 2
             = 4 * 3 + 2 = 14 (alpha, gamma, beta per channel + intercept + sigma)

Key Shapes:
  Raw input:           (52, 5)      - 4 spend columns + 1 conversions
  Internally:          (52, 4)      - spend data only
  Trace posterior:     (2, 500, 4)  - chains × draws × dims (per param)
  Summary:             (14, 9)      - params × statistics
  Contributions:       (52, 4)      - weeks × channels
```

---

## 8. Column Name Patterns

### Input Columns
- Media: `channel_0`, `channel_1`, ..., `channel_N`
- Target: `conversions`

### Posterior Summary Index (Parameter Names)
- Saturation curve: `alpha[0]`, `alpha[1]`, ..., `alpha[N]`
- Half-saturation: `gamma[0]`, `gamma[1]`, ..., `gamma[N]`
- Effectiveness: `beta[0]`, `beta[1]`, ..., `beta[N]`
- Baseline: `intercept`
- Noise: `sigma`

### Contributions Columns
- Attribution: `channel_0`, `channel_1`, ..., `channel_N` (same as input media columns)

## 9. Data Type Summary

| Stage | Structure | Dtype | Mutability |
|-------|-----------|-------|-----------|
| Raw Input | DataFrame | float64 | Immutable |
| Numpy Arrays | ndarray | float64 | Immutable |
| PyMC Variables | PyMC/PyTensor | Tensor | Immutable (during sampling) |
| Trace | InferenceData | float64 | Immutable |
| Summary | DataFrame | float64 | Immutable |
| Contributions | DataFrame | float64 | Immutable |
